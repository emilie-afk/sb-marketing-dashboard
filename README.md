# Marketing Dashboard

**Designed and built by Emilie Ngo for Succulents Box.**

An internal workspace for the Succulents Box marketing team. It brings performance reporting, product and vendor analysis, campaign and promotion planning, and team follow-up into one place.

## Features

- Compare business and channel performance across reporting periods.
- Explore product and vendor performance alongside revenue, profit, and advertising results.
- Review weekly and monthly reports, seasonal promotions, and tasks in the same workspace.

## Connected projects

The Dashboard can pull reporting from these projects when configured.

| Project | What it contributes |
| --- | --- |
| [Gross Profit](https://github.com/emilie-afk/sb-gross-profit) | Profit and cost reporting |
| [Plant Breakdown](https://github.com/emilie-afk/sb-plant-breakdown) | Product and vendor sales analysis |
| [Task Tracker](https://github.com/emilie-afk/sb-task-tracker) | Task snapshots |
| [Corporate Gifts](https://github.com/emilie-afk/sb-corporate-gifts) | Corporate gifting reporting |

## Standalone tools

The [Marketing Toolbox](https://github.com/emilie-afk/sb-marketing) is a directory for opening separate apps, including [Keyword Intelligence](https://github.com/emilie-afk/sb-keyword-intelligence), [Blog Generator](https://github.com/emilie-afk/sb-blog-gen), and [Content Intelligence](https://github.com/emilie-afk/sb-content-intelligence).

## Tech stack

React, TypeScript, Vite, Netlify Functions, and PostgreSQL.
